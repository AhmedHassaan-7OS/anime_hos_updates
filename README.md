# My Apps Update Center

المستودع الرسمي لتوزيع حزم التثبيت والتحديثات الدورية لتطبيقات الويندوز الخاصة بي.

---

## التطبيقات المتاحة حالياً

1. **Hos Watcher (Anime HOS)**  
   تطبيق لمشاهدة ومتابعة الأنمي والمانجا على نظام Windows بمحرك وسائط مبني بلغة Rust.

2. **hosselfishnet**  
   أداة متطورة لإدارة سرعات الشبكة المحلية (LAN)، فحص الأجهزة المتصلة وتحديد أو حظر استهلاك الإنترنت مبنية بـ Flutter و Rust بواجهة Fluent عصرية.

3. *تطبيقات وأدوات أخرى ستضاف هنا مستقبلاً.*

---

## أنواع ملفات التثبيت والتحديث

* **مثبت تلقائي (Setup.exe):** لتثبيت البرنامج بالكامل وتجهيز الاختصارات وإعدادات النظام.
* **نسخة محمولة (Portable.zip):** تعمل مباشرة بدون تثبيت في أي مجلد تختاره.
* **حزم الباتش (Delta Patches):** للتحديثات السريعة؛ يتم تنزيل ملف مضغوط صغير (عادة بين 2 إلى 5 ميجابايت) يحتوي فقط على الأجزاء المعدلة من الكود والمكتبات بدون الحاجة لإعادة تحميل التطبيق بالكامل.
